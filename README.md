# Milestone 2: before and after

Pictures for the pull request "Milestone 2: the fast renderer under the same drawing".
This branch holds nothing else and is never merged.

- `full/`: every stop on the rail, before (the SVG, `?original`) and after (the renderer,
  as the site chose it: WebGPU), photographed by `e2e/chip.spec.ts` in Chromium on an Apple M4,
  1280 x 820 at 2x.
- `pairs/`: the same, before and after side by side at half size.
- `limits/`: enlarged crops, SVG | renderer | difference (differences four times stronger; red
  where the renderer is darker, blue where it is lighter), from the comparison in software.
  `oort-cloud-dots-on-the-chip-2x.png` is the SVG (left) and the renderer (right) on the M4,
  eight times enlarged.
